# Métodos de Ordenamiento Avanzados en Python

Programa interactivo con menú de opciones que reúne cuatro ejercicios prácticos de ordenamiento en un solo archivo (`metodos_ordenamiento_avanzados.py`). Antes de solicitar los datos, el sistema muestra instrucciones claras sobre qué números se pueden ingresar y cuáles no, y presenta paso a paso cómo se ordena la lista.

## Ejercicios incluidos

1. **ShellSort – Tiempos de carga (ms):** Ordena de menor a mayor tiempos de respuesta (números mayores a 0) comparando elementos separados por saltos que se van reduciendo en cada vuelta.
2. **Quicksort – Balances financieros:** Ordena ganancias, pérdidas y días sin movimiento (números positivos, negativos o cero) dividiendo la lista en grupos más pequeños a partir de un valor de referencia.
3. **Heapsort – Prioridad de paquetes:** Ordena puntajes de prioridad (positivos, negativos o cero) localizando el valor más grande en cada recorrido para enviarlo al final de la lista.
4. **Radix Sort – Folios de pedido:** Ordena identificadores numéricos (únicamente enteros positivos o cero) revisando sus cifras de derecha a izquierda, sin comparar números entre sí.

## Requisitos
* Tener instalado **Python 3**.

## Cómo ejecutarlo
1. Abre una terminal en la carpeta donde guardaste el archivo `metodos_ordenamiento_avanzados.py`.
2. Ejecuta el comando:
   ```bash
   python metodos_ordenamiento_avanzados.py
   ```
3. Selecciona en el menú el ejercicio que deseas probar (opciones `1` a `4`), lee las reglas de captura en pantalla e ingresa la cantidad de datos y los números solicitados. Para terminar, elige la opción `5`.
